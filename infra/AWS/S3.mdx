# S3란?
- 무한 확장 가능한 객체 스토리지입니다.
- 백업, 재해복구, 정적 웹 호스팅, 데이터 레이크 등에 쓰임

## Bucket
- 파일을 담는 디렉토리 개념
- 전 세계에서 이름이 고유해야 함
- 리전 단위로 생성 됨
- 이름 규칙: 소문자/숫자/하이픈만, 3~63자, 대문자·밑줄·IP주소 형태 금지

## 보안
- IAM 정책: 사용자 단위 권한
- 버킷 정책: 버킷 전체에 적용되는 JSON 규칙
- 접근 허용 조건
- Block Public Access: 정책으로 공개 설정해도 이 옵션이 켜져있으면 무조건 비공개 유지

## 버전
- 버킷 단위로 켜고 끔
- 같은 키를 덮어쓰면 버전 증가
- 삭제 = 실제 삭제 아니고 삭제 마커 추가 -> 복구 가능

## 복제 
- 소스, 대상 버킷 둘 다 버전관리 켜져있어야 함
- CRR(리전간) / SRR(같은 리전)
- 비동기, 활성화 이후 생선된 객체만 복제된

### 스토리지 클래스 (자주 쓰는 순)

클래스	특징
Standard	가용성 99.99%, 자주 쓰는 데이터
Standard-IA	저렴, 재해복구/백업용, 검색비용 있음
One Zone-IA	단일 AZ, 더 저렴, 재생성 가능한 데이터용
Glacier Instant Retrieval	밀리초 검색, 최소 보관 90일
Glacier Flexible Retrieval	분~시간 단위 검색, 최소 보관 90일
Glacier Deep Archive	12~48시간 검색, 최소 보관 180일, 장기보관 최적
Intelligent-Tiering	사용 패턴 보고 자동으로 계층 이동, 검색비용 없음
내구성(Durability)은 모든 클래스 동일 (99.999999999%)
가용성(Availability)만 클래스별로 다름

# onpremise란?
기업의 서버를 클라우드 같은 원격 환경에서 운영하는 방식이 아닌 자체적으로 보유한 전산실 서버에 직접 설치해 운영하는 방식을 의미합니다.

온프레미스 클라우드 컴푸팅 기술이 나오긴 전까지 기업 인프라 구축의 일반적인 방법이었습니다.

### 장단점
| 구분 | 온프레미스 | 클라우드 |
| --- | --- | --- |
| 서버 | 직접 구매 및 구축 | 필요한 만큼 임대 |
| 초기 비용 | 높음 | 낮음 |
| 운영 | 직접 관리 | 클라우드 사업자가 일부 관리 |
| 확장성 | 장비 추가가 필요해 느림 | 빠르게 확장 가능 |
| 통제권 | 높음 | 상대적으로 낮음 |

# index란?
인덱스는 데이터베이스에서 데이터를 빠르게 조회하기 위한 자료구조입니다.
책의 목차나 색인처럼, 원하는 데이터가 어디에 있는지 빠르게 찾을 수 있게 해줍니다.

* 하나 또는 여러 개의 컬럼을 기준으로 생성할 수 있음
* SELECT, WHERE, ORDER BY, JOIN 등의 조회 성능을 높일 수 있음
* 테이블 전체 데이터를 저장하는 것이 아니라 주로 인덱스 키와 실제 데이터 위치 정보를 저장함
* 별도의 저장 공간이 필요함
* 데이터 조회는 빨라지지만 INSERT, UPDATE, DELETE 시 인덱스도 같이 수정해야 하므로 쓰기 성능은 떨어질 수 있음

## 인덱스의 종류
- B(Balanced)-tree Index
- Bitmap Index
- IOT Index
- Clustered Index
위와 같이 존재하며 주로 B-tree 구조로 사용됩니다.

## 왜 사용할까?
* 인덱스 없음 → 테이블 전체를 확인할 수 있음
* 인덱스 있음 → 필요한 데이터 위치를 빠르게 찾음
* 대신 쓰기 작업에는 비용 발생

## 어떻게 동작할까?
- 특정 컬럼을 기준으로 인덱스를 생성
- 조회 조건이 인덱스와 맞으면 인덱스를 먼저 탐색
- 인덱스에서 실제 데이터의 위치를 찾아 결과를 반환

# CPU란?

CPU란 중앙처리장치라고 합니다.
말 그대로 컴퓨터의 중앙에서 모든 데이터를 처리하는 장치입니다.
컴퓨터의 두뇌에 해당되는 것입니다.
사용자로부터 입력 받은 명령어를 해석, 연산한 후 그 결과를 출력하는 역할입니다.
CPU에는 연산, 해독, 제어 장치가 집적되어 있어서 마이크로프로세서라고도 부릅니다.
CPU의 성능을 설명할 때 대표적인 단위로 클럭입니다.
1초당 CPU 내부에서 몇단계의 작업이 처리되는지를 측정하여 주파수 단위인 헤르츠로 나타낸것입니다.
클럭 수치가 높을수록 빠른 성능의 CPU라고 할 수 있습니다.
하지만 클럭만 지나치게 높이면 발열이 많아지고 전력소모도 심해질 수 있습니다.

## 코어

예전에는 1개의 CPU 당 1개의 코어(싱글 코어)만 있는 것이 당연했지만, 2005년 듀얼 코어 CPU가 등장하면서 하나의 칩에 2개 이상의 코어를 탑재한 멀티 코어 CPU가 대중화 되었습니다.
그래서 요즘은 클럭 속도 외에도 코어의 수가 CPU의 성능을 나타내는 또 하나의 기준이 됩니다.
멀티 코어 CPU는 싱글 코어 CPU를 동시에 설치한 것과 유사한 성능을 냅니다.
싱글 코어가 2번에 걸쳐 처리해야 하는 작업을 듀얼 코어는 두개의 코어가 동시에 작업해서 1번에 끝낼 수 있습니다.
다만 멀티 코어 연산에 최적화된 소프트웨어가 있어야만 효과를 볼 수 있습니다.
멀티 코어를 지원하지 않는 소프트웨어라면 오히려 클럭이 높은 싱글 코어 CPU가 더 나은 경우도 많습니다.
| 코어 수 | 이름 |
| --- | --- |
| 1개 | 싱글 코어 (Single Core) |
| 2개 | 듀얼 코어 (Dual Core) |
| 4개 | 쿼드 코어 (Quad Core) |
| 6개 | 헥사 코어 (Hexa Core) |
| 8개 | 옥타 코어 (Octa Core) |

## 캐시 메모리

캐시 메모리는 CPU 내부의 임시 저장공간으로, CPU가 자주 사용하는 데이터를 임시로 보관하는 곳입니다.
캐시가 작으면 RAM이나 보조기억장치(HDD, SSD 등)에서 데이터를 직접 불러오는 빈도가 높아지는데, 이들은 CPU보다 훨씬 느리기 때문에 전체 처리 속도가 떨어집니다.
따라서 캐시 메모리는 클수록 성능이 좋습니다.
캐시 메모리는 CPU 코어와의 위치에 따라 L1, L2, L3 캐시로 나뉘고, 코어에 가까울수록 빠르지만 만들기 어렵고 비쌉니다.
캐시의 구성 방식과 용량이 CPU의 등급과 가격을 결정하는데 큰 영향을 미칩니다.

## 아키텍처

아키텍처란 CPU의 구조, 설계 방식, 제조 공정을 말합니다.
클럭, 코어 수, 캐시 용량이 모두 같더라도 아키텍처가 다르면 성능에 차이가 납니다.
자동차로 비유하면 배기량이 같아도 연식이나 시리즈에 따라 출력이 다른 것과 비슷합니다.

# RAM이란?
컴퓨터의 주기억장치인 RAM은 컴퓨터가 켜져 있을 때만 사용하고 컴퓨터의 전원이 끊어지면 기록된 정보가 사라지는 휘발성 메모리라는 뜻으로, 응용 프로그램의 일시적 로딩, 데이터의 일시적 저장 등에 사용됩니다.
CPU와ㅇ HDD, SDD 등을 이어주는 또 하나의 데이터 기억장치의 역할로 일을 빠르게 처리할 수 있도록 도와줍니다.
## 램이 중요한 이유
CPU와 저장장치를 연결시켜주어 훨씬 빠른 속도로 컴퓨터를 실행해주는 역할을 합니다.
따라서 램이 높을수록 컴퓨터가 매우 빠르고 다양한 작업을 동시에 처리할 수 있습니다.
램이 부족하면 가상 메모리파일을 사용하게 되는데 램보다 대략 6만배는 느리다고 합니다.
## 용량별 능력치
| 램(RAM) 용량 | 능력치 |
| --- | --- |
| 4GB | 웹서핑, 문서작업 등 간단한 작업 가능 (동시작업 불가능) |
| 8GB | 가벼운 캐주얼게임 가능 (동시작업 버벅거림) |
| 16GB | CPU의 사양도 같이 맞을 때, 고사양의 게임과 디자인작업도 가능 |
| 32GB | 고화질디자인 작업, 영상편집 수월하게 가능, 고사양 게임 대부분 가능 |
| 64GB | 4K급 고화질 영상편집과 다양한 동시작업 가능 |
